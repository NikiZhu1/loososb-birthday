# FISH EXECUTION

Промо-страница события в стилистике Minecraft, пиксельных интерфейсов и глитч-анимаций.

[Перейти на сайт](https://fish-execution.vercel.app)

![FISH EXECUTION](./assets/images/skreenshot.jpg)

![FISH EXECUTION](./assets/images/skreenshot2.jpg)

## Что внутри

- 3D-витрина персонажей с меняющимся видео-фоном;
- видео-ролики и таймер события, ссылки на Telegram и Twitch;
- блок общего доната с DonationAlerts 
- адаптивная вёрстка.

## Фичи

Развёрнуто с помощью Vercel. Использован Cloudflare Worker для работы с API DonationAlerts, для показа общей суммы донатов.
